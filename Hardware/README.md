# 🤖 Eurobot 2026 — Hardware & Design

Aquí se centralizan todos los archivos de **diseño físico**, **electrónica** y **modelado 3D** del robot para la competición **Eurobot 2026**.

---

## 📂 Estructura del Repositorio

La sección de Hardware se divide en **tres pilares fundamentales**:

---

### ⚙️ 1. Componentes

Contiene las librerías de piezas individuales y activos estándar utilizados en el ensamblaje.

| 🔧 Categoría  | 📦 Contenido                                                                |
| ------------- | ---------------------------------------------------------------------------- |
| 🤖 Motores    | Modelos y soportes para **Servos**, motores y sistemas de garras             |
| 📡 Sensores   | Archivos para **HC-SR04** y **RPLidar C1**                                   |
| 🧠 Control    | Modelos de **Raspberry Pi**                                                  |
| 📦 Miscelánea | Baterías, rodamientos, microswitches y otros componentes auxiliares          |
 

---

### ⚡ 2. Electrónica

Aquí se encuentra toda la electrónica y la distribución de potencia del robot.

| ⚡ Sección            | 📄 Contenido                                                     |
| -------------------- | ---------------------------------------------------------------- |
| 🧩 Esquemas KiCad    | Archivos del diseño eléctrico listo para modificarlo               |
| 🔌 Esquema eléctrico | Referencia rápida del cableado y conexionado en formato PDF      |

---

### 🏗️ 3. Modelos 3D

Ensamblajes principales y diseños mecánicos complejos del robot.

| 🏗️ Categoría | 📦 Contenido                                             |
| ------------- | -------------------------------------------------------- |
| 🚗 Chasis     | Diseños del **Chasis** del Robot                         |
| 🦾 Mecanismos | Diseño de la **Garra** y sistema de elevación            |
| 📦 Cajas      | Diseños como **CajaBellota**                             |

---

## 🛠️ Herramientas Utilizadas

| 🧰 Tipo | 🔧 Herramientas                                      |
| ------- | ---------------------------------------------------- |
| 🧱 CAD  | SolidWorks (`.SLDPRT`, `.SLDASM`) + formatos `.STEP` |
| ⚡ EDA   | KiCad (diseño de circuitos impresos)                 |
